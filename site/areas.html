Условия области

Сопровождайте приложение для области «Магазин спортивной обуви»: воспроизведите и исправьте дефекты D1–D5 в своей копии исходного проекта. Категория и обозначения размеров определяются каждым товаром отдельно. Ниже приведён состав именно вашего набора; сверяйте с ним каталог после замены data.json.

Товары и обозначения размеров

P1 — Кроссовки для бега; категория «Обувь»; варианты размера: 38 — остаток 5, 39 — остаток 3.
P2 — Кеды для зала; категория «Обувь»; варианты размера: 38 — остаток 2, 39 — остаток 1.
P3 — Сумка для обуви; категория «Аксессуары»; варианты размера: 30×40 см — остаток 3, 35×45 см — остаток 2.
P4 — Стельки спортивные; категория «Аксессуары»; варианты размера: 38 — остаток 3, 39 — остаток 2.
P5 — Кроссовки для бега — резервная модель; категория «Обувь»; варианты размера: 38 — остаток 2, 39 — остаток 0.

Назначение данных

Это подготовленные учебные данные для этой области. Цены являются условными контрольными значениями, подобранными для проверки числовой сортировки и округления; они не описывают рыночный прайс. Пользователи client и buyer — тестовые учётные записи без пароля. Производители условные. Пустой ImagePath проверяет предусмотренную заглушку «Нет изображения»; добавление фотографий не требуется для исправления D1–D5.

Материалы и порядок работы

Общий Shop-source.zip содержит демонстрационный магазин обуви. Создайте из него отдельную копию для области «Магазин спортивной обуви», затем замените корневой data.json файлом variant-01.json, переименовав его в data.json. Перестройте проект; убедитесь, что заголовок и все пять товаров относятся к этой области. Архив Shop-fixed-example.zip содержит исправленный демонстрационный магазин обуви: сравнивайте с ним причины и методы после диагностики, не заменяйте им свой проект и свои данные.

Контрольные данные

У первой модели остатки двух размеров равны 5 и 3. У резервной модели второй размер недоступен. Логины client и buyer принадлежат разным пользователям; смена выполняется через «Выйти». История заказов первоначально пуста. Для «Кроссовки для бега» закажите 2 единицы первого размера: остаток станет 3, второй останется 3. Категории и размеры остальных товаров проверьте в JSON: принадлежность товара определяется его назначением, размеры разных товаров могут различаться. Price содержит условную базовую цену; при пустой истории DiscountPrice рассчитывается как Price × 0,75 с округлением до двух знаков. Начальный ноль в DiscountPrice не является ценой продажи.

Самостоятельная проверка: Равная цена разных моделей

У P1 и P2 одинаковая базовая цена. До запуска определите порядок при равенстве DiscountPrice по Id. Проверьте обе сортировки и повторное уточнение поиска. Объясните, почему равные цены не требуют случайной перестановки строк. Для каждого перехода запишите исходные условия, ожидание до запуска и фактический результат; объясните причину расхождения, если оно обнаружено.

Ожидаемый результат

Составьте запись обращения → причина → изменение → повторная проверка → регрессия для каждого дефекта. Подтвердите заказ нескольких позиций, проверьте дату, остатки и сохранение после перезапуска. Подготовьте инструкцию пользователю с примерами своей области. При сдаче проекта приложите ссылку на его репозиторий.
