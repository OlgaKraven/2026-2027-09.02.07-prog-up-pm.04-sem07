# Проверка комплекта УП ПМ.04

Область проверки: учебная практика ДКИП-4ХХпрог, 10–30 ноября 2026, 108 часов. Исторические материалы в evidence сохранены. Этот файл относится к разработке и не включается в учебные страницы.

## Изменение объёма

В исходном RepairLogic остались D1 (запасной выбор первого пользователя), D2 (очистка заявки при возврате), D3 (объединение отбора через OR и сравнение стоимости как строки). В исправленной версии устранены эти причины. OrderService одинаков в обеих версиях: количество и подтверждение заявки предоставлены готовыми. Состав вариантов изменён на 30 областей обслуживания оборудования. Торговые области не используются.

## Выполненные проверки

- Обе WPF-версии собраны на .NET SDK 10.0.401 без ошибок и предупреждений.
- Консольная приёмка использует реальные исходники компонентов. На всех 30 наборах исходная версия воспроизводит три диагностических расхождения и сохраняет работоспособную операцию заявки: 690 проверок. Исправленная версия проходит 841 проверку: вход, возврат, совместный отбор, числовая сортировка, отказы количества, исправление ввода, отсутствие частичного списания, подтверждение нескольких позиций, JSON roundtrip. Отдельно проверен перенос отбора на другую модель Sensor без переписывания алгоритма.
- В фактическом WPF-окне проверены начальный каталог, отказ nobody с сохранением поля и успешный вход client после исправления. Снимок отказа сохранён рядом с остальными доказательствами. Продолжение интерактивного прохода ограничено состоянием свёрнутого окна; его не следует считать полным ручным проходом всех вариантов. Остальные переходы проверены по коду и тестами компонентов.
- Проверены три страницы сайта при ширине 390 px; горизонтального переполнения нет. Проверены выбор последнего варианта, его отдельные данные, состояние кнопок и адресный переход. Проверены локальные ссылки, соответствие ZIP исходникам и наличие готовой операции в обоих архивах.
- PDF: методические рекомендации — 19 страниц; предметные области — 91 страница. Сверены все названия областей, отсутствие D4/D5 в выдачах, нумерация этапов и наличие фрагментов кода. Выполнен обзор отрисовок методички и детальный осмотр разных макетов, начального и последнего вариантов. Учебные PDF используют явно запрошенный современный профиль навыков: тёмная шапка, красный акцент, серые блоки, Golos Text; это не заявление о полном соответствии типографическому профилю ГОСТ.

## Повторение проверки

Из корня репозитория:

```text
python -B tools/build.py
node tools/export_pdf.cjs
python -B tools/build.py
dotnet build stands/Shop-source/Shop.csproj
dotnet build stands/Shop-fixed/Shop.csproj
dotnet run --project tools/Acceptance/Acceptance.csproj -- .
dotnet run --project tools/Acceptance/Acceptance.csproj -p:VersionFolder=Shop-source -- . --source
```

Экспорт PDF требует Node.js, Playwright и Chromium. Python использует стандартную библиотеку. Второй запуск build.py обновляет контрольные суммы после экспорта PDF. Служебные материалы и результаты испытаний не входят в исходные студенческие ZIP.

## Границы подтверждения

Это проверка комплекта и компонентов, без испытания со студентами. Не подтверждаются работа с БД, конкурентные транзакции и полный запуск всех дополнительных сценариев через графический интерфейс. Независимый тест начинается с восстановленного baseline.json своей области. Даты и объём других практик, включая производственные назначения ДКИП-311прог, сюда не переносятся.

## Дополнительный проход после проверки иллюстраций

Восстановлены подробные пояснения и 14 предметных снимков актуального сервисного стенда. Выполнен фактический проход исходных D1–D3, отказа и исправления количества, двух позиций, подтверждения и повторного запуска. Сохранённый JSON проверен отдельно от UI. Предыдущая оговорка об ограничении ручного прохода только входом относится к первому этапу; дополнительный проход закрывает стандартный маршрут демонстрации. Матрица покрытия находится в «Охват задания и иллюстраций.md». Из учебной выдачи исключены отсылки к другим практикам; пользовательские изменения кафедры и литературы сохранены.
