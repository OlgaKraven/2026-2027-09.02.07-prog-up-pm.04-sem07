# Учебная практика ПМ.04 — сопровождение программного обеспечения

Учебная практика для 4 курса, 7 семестра, специальности 09.02.07 «Информационные системы и программирование», квалификация «Программист».

Студент сопровождает готовое приложение C# WPF: воспроизводит дефекты входа, навигации, совместного поиска, фильтрации и сортировки, проверки количества и оформления заказа; находит причины, исправляет компоненты и выполняет повторные и регрессионные проверки. Демонстрационная область — магазин обуви «Пара»; предусмотрены 30 самостоятельных предметных областей.

Исходный проект содержит намеренные дефекты для диагностики; исправленный демонстрационный пример предназначен для сверки после самостоятельного анализа. Файлы вариантов содержат исходные данные, а не готовые индивидуальные решения.
